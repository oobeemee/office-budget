# 💰 Office Budget — Система учета офисного бюджета

Веб-приложение для управления финансами компании, отслеживания доходов и расходов, а также обработки заявок сотрудников на выделение средств.

## ✨ Возможности

*   **Ролевая модель:** Разделение прав доступа (Администратор, Оператор, Пользователь).
*   **Дашборд:** Визуализация статистики (доходы/расходы) с помощью графиков (Chart.js).
*   **Транзакции:** Учет поступлений и трат с возможностью прикрепления чеков (сканов).
*   **Система заявок:** Пользователи могут подавать заявки на расходы, а руководство — одобрять или отклонять их.
*   **Отчетность:** Экспорт данных в **Excel (XLSX)** и CSV.
    *   Включает детальный отчет «Движение средств».
    *   Аналитический отчет «Расходы по категориям» с диаграммами.
*   **Логирование:** Автоматическая запись ошибок сервера в файл для отладки.

## 🛠️ Технологический стек

*   **Backend:** PHP 8.2 (PDO, OOP).
*   **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript (ES6+).
*   **Database:** MySQL / MariaDB.
*   **Libraries:**
    *   `PhpSpreadsheet` (генерация Excel).
    *   `Chart.js` (графики).
*   **DevOps:** Composer.

## 🚀 Установка и запуск

### Локально (XAMPP / OpenServer)

1.  **Копирование файлов:**
    *   Переместите файлы проекта в папку веб-сервера (например, `C:\xampp\htdocs\`).

2.  **Настройка базы данных:**
    *   Откройте phpMyAdmin.
    *   Создайте базу данных с именем `office_budget_local` (кодировка `utf8mb4_general_ci`).
    *   Импортируйте файл `dump.sql` (находится в корне проекта).

3.  **Установка зависимостей:**
    *   Откройте терминал в папке проекта.
    *   Выполните команду (нужен установленный Composer):
        ```bash
        composer install
        ```

4.  **Настройка конфигурации:**
    *   Убедитесь, что данные в `config/database.php` соответствуют вашим (по умолчанию: user `root`, пароль пустой).

5.  **Запуск:**
    *   Откройте в браузере: `http://localhost/`
